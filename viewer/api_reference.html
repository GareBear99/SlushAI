🌐 Public API Endpoints

These endpoints are publicly accessible without authentication. All responses include a _meta field with endpoint descriptions and field documentation.

GET /api/health No rate limit

Purpose: Server health check and status verification. Returns server timestamp and operational status.

Response Fields:

ok
Boolean indicating server is operational
time
Current Unix timestamp (seconds since epoch)
outputs_dir
Absolute path to model outputs directory
_meta
Endpoint metadata with field descriptions
JavaScript Example 
// Check server health
fetch('http://localhost:5000/api/health')
  .then(res => res.json())
  .then(data => {
    console.log('Server status:', data.ok);
    console.log('Timestamp:', data.time);
    console.log('Outputs dir:', data.outputs_dir);
  });
GET /api/capacity No rate limit

Purpose: Real-time platform capacity and usage statistics across all subscription tiers. Shows user counts, available slots, worker status, and processing queue.

Response Structure:

capacity.{tier}.current
Number of registered users in this tier
capacity.{tier}.max
Maximum allowed users for this tier
capacity.{tier}.available
Remaining slots available for new users
capacity.{tier}.percent_full
Percentage of tier capacity currently used
capacity.workers.active
Current number of active worker processes (1-20)
capacity.workers.processing
Number of models currently being generated
capacity.workers.queue_length
Number of pending generation tasks in queue
capacity.workers.total_processed
Total models generated since server start
JavaScript Example 
// Fetch platform capacity
fetch('http://localhost:5000/api/capacity')
  .then(res => res.json())
  .then(data => {
    console.log('Metadata:', data._meta);
    console.log('Free tier:', data.capacity.free);
    console.log('Workers:', data.capacity.workers);
    
    // Check if tier has availability
    const free = data.capacity.free;
    if (free.available > 0) {
      console.log(`Free tier: ${free.available} slots available`);
    } else {
      console.log('Free tier at capacity');
    }
  });

POST /api/check-username 30/min per IP

Purpose: Check if a username is available for registration. Used for real-time validation during signup.

Request Body:

{
  "username": "string"
}

Response:

{
  "available": boolean,
  "message": "string"
}

Validation Rules:

  • 3-20 characters
  • Alphanumeric + underscore only
  • Must start with letter
  • Case-insensitive uniqueness check
JavaScript Example 
// Check username availability
fetch('http://localhost:5000/api/check-username', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    username: 'johndoe'
  })
})
  .then(res => res.json())
  .then(data => {
    if (data.available) {
      console.log('✓ Username available');
    } else {
      console.log('✗ ' + data.message);
    }
  });

📝 Example Usage

Complete Integration Example 
// Complete SlushAI API integration example

class SlushAI {
  constructor(baseURL = 'http://localhost:5000') {
    this.baseURL = baseURL;
  }

  async checkHealth() {
    const response = await fetch(`${this.baseURL}/api/health`);
    return await response.json();
  }

  async getCapacity() {
    const response = await fetch(`${this.baseURL}/api/capacity`);
    return await response.json();
  }

  async checkUsername(username) {
    const response = await fetch(`${this.baseURL}/api/check-username`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ username })
    });
    return await response.json();
  }

  async displayDashboard() {
    const [health, capacity] = await Promise.all([
      this.checkHealth(),
      this.getCapacity()
    ]);

    console.log('=== SlushAI Dashboard ===');
    console.log('Server Status:', health.ok ? '✅ Online' : '❌ Offline');
    console.log('Free Tier:', `${capacity.capacity.free.available} slots available`);
    console.log('Workers Active:', capacity.capacity.workers.active);
    console.log('Queue Length:', capacity.capacity.workers.queue_length);
  }
}

// Usage
const api = new SlushAI();
api.displayDashboard();

⚡ Rate Limits

Different endpoints have different rate limits to ensure fair usage:

  • No limit: /api/health, /api/capacity
  • 30/min per IP: /api/check-username
  • 100/min per IP: Public documentation pages
  • 5/hour per IP: Signup, support requests

Rate limit exceeded responses return HTTP 429 with Retry-After header.

🔒 Authentication

Protected endpoints require authentication via session cookies. Public endpoints listed above do not require authentication.
