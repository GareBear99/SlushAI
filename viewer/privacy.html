5. Data Security

5.1 Security Measures

4-Level Progressive Blocking System:

  • Level 1: Rate limit warning (429 error)
  • Level 2: Temporary block (1 hour for sustained >100 req/min)
  • Level 3: Extended block (24 hours for attack patterns)
  • Level 4: Permanent ban (DDoS attacks >1000 req/10s)

Attack Detection:

  • SQL injection detection and blocking
  • XSS (Cross-Site Scripting) prevention
  • Path traversal protection
  • Command injection prevention
  • DDoS protection
  • Brute force attack detection

Encryption & Authentication:

  • HTTPS/TLS for data in transit
  • Password hashing with bcrypt (12+ rounds)
  • Secure session management
  • IP address hashing (SHA256) for lookup, with the original IP retained in the visitor log

5.2 Security Limitations

⚠️ Important: No system is 100% secure. Despite our comprehensive security measures, you acknowledge the inherent risks of internet transmission.

User Responsibility: Use strong unique passwords, don't share credentials, report security vulnerabilities responsibly, keep your device updated.
